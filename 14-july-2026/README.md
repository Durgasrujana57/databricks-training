# 📘 SQL Practice Questions

A collection of SQL practice questions covering fundamental SQL concepts using an Employee dataset for hands-on learning and interview preparation.

---

## 🚀 Tasks Completed

- Solved SQL queries using **SELECT**
- Filtered records using **WHERE**
- Performed aggregations using **GROUP BY**
- Applied conditions using **HAVING**
- Retrieved top records using **ORDER BY** and **LIMIT**
- Extracted unique values using **DISTINCT**
- Used comparison operators (`=`, `>`, `<`, `>=`, `<=`, `<>`)
- Applied logical operators (**AND**, **OR**, **NOT**)
- Filtered records using **IN** and **NOT IN**
- Retrieved records using **BETWEEN**
- Performed pattern matching using **LIKE**
